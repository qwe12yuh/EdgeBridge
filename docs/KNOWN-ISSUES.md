# 已知问题与路线

当前版本为开发者预览。普通 PPT 的双向手动拖放已通过，详细证据见 [验证记录](../VALIDATION.md)。

- **Windows 迟到回执误报**：OLE 目标处理可能超过 2 秒；原生最终返回 DROP + COPY，当前协调器仍可能先记录 cancelled。用户已确认该次实际回拖成功，日志不能替代落点确认。后续需分开“物理手势结束”和“目标处理复制”，避免等待结果时继续占用普通点击。
- **完整暂存与 64MiB 限制**：目前没有跨机文件承诺/虚拟流，大文件不能在传完前完成交接。
- **部署尚需手动完成**：双端构建、TLS 配对、SSH 隧道、Deskflow 外部适配器和 macOS 辅助功能授权。没有安装器、自动发现、正式签名或开机自启。
- **更多交互待验收**：多文件/目录拖放、快速移动并松手、不同目标应用、Esc、断线、休眠与重连。

发布包只提供源码；不含已签名的安装程序、配对凭证或正在运行机器的配置。旧 `bridge.mjs` 是早期实验，不应与 `gesture-lab.mjs` 同时运行。
